Drop the command-line tools here (the installers in `install/` do this for you):

| Windows        | macOS     |
|----------------|-----------|
| `yt-dlp.exe`   | `yt-dlp`  |
| `ffmpeg.exe`   | `ffmpeg`  |
| `ffprobe.exe`  | `ffprobe` |
| `deno.exe`     | `deno`    |

Anything missing here is looked up on PATH and in the usual Homebrew / winget / scoop locations.
