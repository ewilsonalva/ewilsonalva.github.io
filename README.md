# Ewilson Alva

Portfolio site for Ewilson Alva, cinematic artist, previz artist and AI cinematographer.

The whole site is one self-contained file, `index.html`. Images and logos are embedded in it,
so there are no other assets to upload.

## Editing the site

1. Open the live site and press **Admin** in the top right, then enter the admin password.
2. Click any text to edit it. Right-click a reel, a logo or an image to replace it.
3. Press **Export** in the admin bar. That downloads an updated `index.html`.
4. Replace `index.html` in this repository with the downloaded file and commit. The site updates
   within a minute.
